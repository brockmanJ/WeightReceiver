## 📜 О проекте

**WeightReceiver** — это приложение для получения и обработки весовых данных с весового оборудования. Программа позволяет собирать данные через сеть и сохранять их в структурированном JSON-формате.

## 🎯 Ключевые особенности

* **Автоматическое подключение** к весовому терминалу
* **Сбор данных** в режиме реального времени
* **Сохранение информации** в JSON-формате
* **Гибкая настройка** параметров подключения
* **Обработка ошибок** и восстановление соединения

## 🛠️ Системные требования

* Python 3.6+
* Установленные библиотеки:
  * `socket`
  * `argparse`
  * `datetime`
  * `json`

## 🔌 Установка

Клонируйте репозиторий:
```bash
git clone https://github.com/brockmanJ/WeightReceiver.git
```

## 🎮 Запуск

```bash
python weight_receiver.py --host 127.0.0.1 --port 8080 --file weights.json --interval 5
```

## ⚙️ Параметры запуска

Программа поддерживает следующие параметры командной строки:

| Параметр | Описание |
|----------|-----------|
| `--host` | IP-адрес терминала (по умолчанию: 127.0.0.1) |
| `--port` | Порт подключения (по умолчанию: 8080) |
| `--file` | Файл для сохранения данных (по умолчанию: weights.json) |
| `--interval` | Интервал опроса в секундах (по умолчанию: 5) |

## 📄 Формат выходных данных

Пример записи в JSON-файле:
```json
{
    "timestamp": "2026-02-18T12:00:00",
    "weight": 123.45,
    "source": "TerminalName"
}
```
